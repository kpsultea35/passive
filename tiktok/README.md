# 🎬 CapCut-Ready Production Files (Scripts 1–3)

Everything you need to assemble the first three faceless TikToks. For each script:

- **`*-shotlist.md`** — frame-by-frame plan: every clip, its duration, where to find
  license-free footage (search terms for Pexels/Pixabay/Mixkit), transitions, and audio.
- **`*-overlays.txt`** — the exact on-screen text with timecodes and screen position.
  Copy each line straight into a CapCut Text layer.
- **`*.srt`** — caption/subtitle file. Import for instant timed captions.

## How to build a video in CapCut (free, ~15 min)

1. **New project** → set canvas to **9:16 (1080×1920)**.
2. **Drop your clips** in the order from the shotlist; trim each to its listed duration.
3. **Add on-screen text:** open `*-overlays.txt`, add a Text layer for each block, paste
   the text, and drag it to the listed start/end time and position (top / center).
   - Use a bold font, white text, subtle shadow or black box for legibility.
   - Keep all text **out of the bottom ~20%** (TikTok's caption/UI lives there).
4. **Captions (optional but boosts retention):**
   - Easiest: **Captions → Auto captions** after you add a voiceover, or
   - **Import `*.srt`:** Text → Captions → (your version may show *Import*), or drag the
     `.srt` onto the timeline. If your CapCut build has no SRT import, the `.srt` still
     works when uploading directly in **TikTok → captions**, or just use the overlays.
5. **Voiceover:** record yourself, or use **CapCut → Text-to-speech** on a hidden text
   layer (no face needed). The `.srt` lines are the exact voiceover words.
6. **Audio:** add a **currently-trending sound** from TikTok's library (the shotlist
   notes the *vibe*). Duck it under the voiceover to ~20–30% volume.
7. **Export:** 1080p, 30fps. Post natively in the TikTok app for best reach.
